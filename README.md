# # DevMedicos
# Overview

> Advanced medical inventory management system optimizing pharmaceutical stock control, sales tracking, and comprehensive reporting. Successfully deployed in a pharmacy, providing robust digital infrastructure for medical retail operations.

# Features

> Stock Management: Real-time inventory tracking with automated low-stock alerts, ensuring continuous product availability and proactive restocking.

> Intelligent Billing System: Dynamic pricing calculator with integrated discount mechanisms, enabling precise and flexible transaction processing.

> Automated Reporting: Monthly comprehensive financial reports delivered via email, tracking profit metrics and comparing performance against predefined targets. Automatic vendor notifications for inventory replenishment.

> Intuitive User Interface: Streamlined, user-friendly dashboard designed for seamless navigation and efficient operational management.

# Installation

> Repository Cloning: Clone project repository

> Dependencies: Install npm packages in client and server directories

> Server Initialization: Execute npm run in server folder

> Client Launch: Run npm run dev in client directory

# Technologies Used

> Frontend: Typescript, Tauri, React.js

> Backend: Node.js

> Database: SQLite
